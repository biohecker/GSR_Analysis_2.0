       • Real-time processing log
       • Auto-detects already processed files
       • Built-in terminal instructions

    📁 File: run_incremental_analysis.py
    ⚡ Features:
       • Terminal-based (minimal overhead)
       • Processes ONLY new files (super fast!)
       • Shows what will be processed
       • Auto-updates comparison_metrics.csv
       • Option to force reprocess all (--force)
       • Smart file detection
    🎯 Best for: Power users, batch processing
    ⏱️  Time to results: ~1 minute for incremental processing

    Launch with:
    $ python run_incremental_analysis.py --config config.yaml
